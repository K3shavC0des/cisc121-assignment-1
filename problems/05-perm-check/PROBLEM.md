# PermCheck — problem brief

Decide whether a nonempty integer list `A` of length `N` contains every number from `1` through `N` exactly once.

Your Python function is `solution(A)`. Return `1` if the list meets that condition and `0` otherwise.

**Examples:** `[4, 1, 3, 2]` → `1`; `[4, 1, 3]` → `0` because it lacks `2`.

**Limits:** `N` is from 1 to 100,000. Each input value is from 1 to 1,000,000,000. The task calls for an efficient algorithm.

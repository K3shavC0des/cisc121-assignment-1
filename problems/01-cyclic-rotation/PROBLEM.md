# CyclicRotation — problem brief

Given an integer list `A` and a nonnegative integer `K`, return a list produced by moving every element `K` positions to the right. Elements that pass the end of the list wrap around to the front. An empty input list stays empty.

Your Python function is `solution(A, K)` and must return the rotated list.

**Example:** `A = [3, 8, 9, 7, 6]`, `K = 3` → `[9, 7, 6, 3, 8]`. Rotating `[1, 2, 3, 4]` four times gives the original list.

**Limits:** The list length and `K` are each from 0 to 100. Each list value is from -1,000 to 1,000. Correctness is the focus for this task.

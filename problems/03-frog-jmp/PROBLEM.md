# FrogJmp — problem brief

A frog starts at position `X` and makes jumps of exactly `D` units. Find the smallest number of jumps needed to reach position `Y` or go beyond it.

Your Python function is `solution(X, Y, D)` and must return that jump count.

**Example:** `X = 10`, `Y = 85`, `D = 30` → `3`. If `X` already equals `Y`, the result is `0`.

**Limits:** `X`, `Y`, and `D` are integers from 1 to 1,000,000,000, and `X` is at most `Y`. The task calls for an efficient algorithm.

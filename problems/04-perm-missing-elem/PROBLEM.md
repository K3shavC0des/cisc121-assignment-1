# PermMissingElem — problem brief

A list `A` contains `N` distinct integers drawn from `1` through `N + 1`. Exactly one number in that range is absent. Find it.

Your Python function is `solution(A)` and must return the missing number.

**Example:** `[2, 3, 1, 5]` → `4`. An empty list has `N = 0`, so its missing number is `1`.

**Limits:** `N` is from 0 to 100,000. All input values are distinct and within `1` through `N + 1`. The task calls for an efficient algorithm.

# OddOccurrencesInArray — problem brief

Given a nonempty list of integers with an odd number of elements, find the one value that cannot be completely paired with identical values. Every other value appears an even number of times.

Your Python function is `solution(A)` and must return that unpaired value.

**Example:** `[9, 3, 9, 3, 9, 7, 9]` → `7`. A one-element list returns its only value.

**Limits:** The list has an odd length from 1 to 1,000,000. Values are from 1 to 1,000,000,000. Exactly one value occurs an odd number of times.
